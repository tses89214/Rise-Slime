# Rise & Slime

A slime bakery idle game whose events feed a real-time data pipeline:
**game / bots → Python collector → Kafka → Flink → ClickHouse → ops dashboard**.

Portfolio project. The pipeline handles duplicates (dedup by `event_id`), late events
(15 min allowed lateness, windows re-emitted), malformed events (dead-letter topic) and
schema evolution (v1 and v2 events coexist).

## Play

In the browser: https://tses89214.itch.io/rise-slime

Or locally (no setup beyond Node):

Needs Node 20+.

```
npm install
npm run dev        # http://localhost:5173, telemetry off
npm test           # vitest
npm run build      # itch.io build: contains no event-sending code
```

## Run the pipeline

Needs Docker, [uv](https://docs.astral.sh/uv/) and Node 20+. Give Docker ~6 GB RAM.

```
npm install
docker compose up -d                                   # Kafka x2, Kafka UI :8080, ClickHouse :8123, Flink :8081
for t in events events.dlq; do docker compose exec -T kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 --create --if-not-exists --topic $t --replication-factor 2; done   # first start only: Flink needs these to exist
docker compose --profile submit run --rm flink-sql     # submit the Flink job (once)
KAFKA_BROKERS=localhost:9092 npm run collector         # collector + dashboard on :3000
npm run bots -- --bots 20 --seconds 600 --speed 60 --url http://localhost:3000/events
```

Then open the dashboard at http://localhost:3000/dashboard.
To feed it from the browser game too: `VITE_TELEMETRY=true npm run dev`.

`docker compose down -v` wipes all data. Ports, start order, tables and
troubleshooting: `docs/system.md`.
